# 重置时间文案生成规则（用于代码实现）

## 输入

一个时间差值 `hours_until_reset`（浮点数，单位：小时），代表距离该服务商额度重置还剩多少时间。

## 输出

一个字符串，格式为 `"{数值} {单位}后重置"`。

## 转换规则（按数量级动态选择精度，从近到远精度递减）

```
if hours_until_reset < 1:
    minutes = round(hours_until_reset * 60)
    输出 = f"{minutes} 分钟后重置"

elif hours_until_reset < 24:
    hours = round(hours_until_reset)
    输出 = f"{hours} 小时后重置"

elif hours_until_reset < 48:
    输出 = "明天重置"

else:
    days = round(hours_until_reset / 24)
    输出 = f"{days} 天后重置"
```

## 边界规则说明

1. **每一档只用一个时间单位，不做单位组合**（不允许出现"3天5小时"或"2小时23分钟"这种复合文案）。
2. **数值统一取整**，不显示小数。
3. **24~48 小时这一档固定显示"明天重置"**，不显示具体小时数或"1 天后"，因为这个区间对用户来说就是"明天"这个心智概念，不需要更精确。
4. **临界值处理**：
   - `hours_until_reset` 恰好等于 1、24、48 时，归入下一档（即用 `<` 判断，不用 `<=`），保证过渡自然。
   - 若 `minutes` 四舍五入后等于 0（比如剩余 20 秒），按最小单位显示 `"1 分钟后重置"`，不显示 "0 分钟后重置"。
   - 若 `hours` 四舍五入后等于 24（比如 23.6 小时因四舍五入变成 24），应重新归入"明天重置"这一档，不显示"24 小时后重置"。同理 `days` 四舍五入为 0 时最少显示 "1 天后重置"。

## 使用位置

此函数在以下两处调用，两处结果必须一致（同一份数据、同一套计算逻辑）：
1. 第一页"推荐使用"结论区的理由文案
2. 第二页"查看额度"列表中每个服务商的重置时间字段

## 函数签名参考（伪代码，具体语言按项目实际调整）

```
function formatResetTime(hoursUntilReset: number): string {
    if (hoursUntilReset < 1/60) {
        return "1 分钟后重置"  // 极端边界，避免出现 0 分钟
    }
    if (hoursUntilReset < 1) {
        const minutes = Math.round(hoursUntilReset * 60)
        return minutes === 0 ? "1 分钟后重置" : `${minutes} 分钟后重置`
    }
    if (hoursUntilReset < 24) {
        const hours = Math.round(hoursUntilReset)
        if (hours >= 24) return "明天重置"  // 四舍五入进位处理
        return `${hours} 小时后重置`
    }
    if (hoursUntilReset < 48) {
        return "明天重置"
    }
    const days = Math.max(1, Math.round(hoursUntilReset / 24))
    return `${days} 天后重置`
}
```
